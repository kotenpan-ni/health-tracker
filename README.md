# 健康管理ノート

食事と体重を記録するシンプルなWebアプリです。

## 主な機能

- **食事記録**: 食品検索または手入力で、カロリー・タンパク質・脂質・炭水化物（PFC）を記録
- **体重記録**: 日々の体重を記録し、推移をグラフで表示
- **プロフィール登録**: 年齢・性別・身長・体重・活動レベル・目標を入力すると、基礎代謝(BMR)や目標カロリー・PFCバランスを自動計算
- **履歴表示**: 過去の記録を一覧で確認可能
- **出産準備チェックリスト**: 陣痛バッグ・入院バッグ・赤ちゃん用品・持参不要品・帰宅後グッズ・検討中事項をカテゴリ別に管理。チェックで完了管理、項目の追加も可能

## 使い方

`index.html` をブラウザで開くだけで動作します。サーバーのセットアップは不要です。

## 技術構成

- HTML / CSS / JavaScript（フレームワーク不使用）
- データはブラウザの `localStorage` に保存されます（サーバーへの送信はありません）

## ファイル構成

- `index.html` — 画面構造
- `style.css` — スタイル
- `script.js` — アプリのロジック
- `foods.js` — 食品データベース
